Conclusion: Solving the Fine-Grained Bird Classification Problem

1. The Core Problem

The image task was to classify CUB-200-2011 bird images into 200 visually similar species. This is a fine-grained recognition problem where many classes differ by small details such as color patterns, wing markings, beak shape, or pose. Because of this, simple pixel-based features are not sufficient.

2. The Solution & Pipeline

  • Preprocessing: resize and crop images to 224×224, apply training augmentation, convert to tensors, and normalize with ImageNet statistics.
  • Feature extraction: use ImageNet-pretrained ResNet-50 as a backbone and export 2048-dimensional embeddings for classical machine-learning models.
  • Model comparison: evaluate Logistic Regression, Random Forest, KNN, and a fully fine-tuned ResNet-50 using accuracy, Top-5 accuracy, macro precision, macro recall, macro F1, inference time, and model size.

3. Final Choice

The fine-tuned ResNet-50 is the best final model for maximum classification quality. It achieves the highest Top-1 accuracy (70.38%), Top-5 accuracy (91.56%), and macro F1 (0.7049), showing that end-to-end adaptation of the CNN features improves fine-grained bird recognition.

For a lightweight deployment scenario, Logistic Regression is the strongest practical baseline. It reaches 65.31% accuracy and 88.95% Top-5 accuracy with very fast inference and a small 3.13 MB model, making it a good trade-off when GPU fine-tuning or large model storage is not available.

Key takeaways

  • Best model: Fine-tuned ResNet-50
  • Top-1 accuracy: 70.38%
  • Top-5 accuracy: 91.56%
  • Best baseline: Logistic Regression on ResNet-50 features
  • Weakest model: KNN, due to lower accuracy and slower per-image lookup
Final verdict: fine-tuned ResNet-50 for quality, Logistic Regression for efficiency
